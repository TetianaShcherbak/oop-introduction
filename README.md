# OOP Introduction

Materiały do kursu "Podstawy OOP w Pythonie" — przykłady i zadania
pokazujące, dlaczego i jak przechodzi się od kodu strukturalnego do
obiektowego.

## Zawartość repo

Repo zawiera dwie części, o różnym przeznaczeniu:

### `rental_shop/` — przykład referencyjny (do wglądu)

Pełny przykład rozwiązania, krok po kroku: kod strukturalny → refaktoryzacja
na OOP → rozszerzenie logiki biznesowej (status studenta) na już
zrefaktoryzowanym kodzie. Służy jako **wzorzec** — pokazuje, jak powinno
wyglądać rozwiązanie zadania, do którego można się odwołać podczas
ćwiczeń lub po nich.


### `internet_shop/` — kod startowy do ćwiczeń

Zawiera **wyłącznie wersję strukturalną**. To baza, na której studenci
samodzielnie wykonują zadanie: najpierw diagnozują problemy kodu
strukturalnego, potem przeprowadzają refaktoryzację na OOP, a na końcu
rozszerzają logikę biznesową (analogicznie do `rental_shop/`) — samodzielnie,
bez podglądania gotowego rozwiązania.
